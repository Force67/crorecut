# <img height="40px" align="top" src="./assets/crorecut.ico">&nbsp;Crorecut

A portable, tiny video editing tool for cropping and chopping some footage, and an FFmpeg wrapper 🎞️

### Features
- Crop
- Resize
- Cut
- Compress
- Adjust volume levels or mute
- Take with you: this is a portable app with only 1 runtime dependency — [FFmpeg](https://www.ffmpeg.org/download.html)

### Download
Get the portable binary <sup>_~15MB_</sup> on the [releases](https://github.com/miredirex/crorecut/releases) page

### Configure
[Get FFmpeg](https://www.ffmpeg.org/download.html) if you don't have it

Then either set FFmpeg `../ffmpeg/bin` in your PATH env variable, or specify the path in UI in the app's settings
